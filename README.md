# ⚡ Power Plant Energy Output Prediction

## 📌 Project Overview

This project analyzes environmental conditions to predict the electrical energy output of a power plant using machine learning regression models.

---

## 🎯 Objectives

* Analyze relationships between environmental variables and energy output
* Perform data cleaning using IQR method for outlier detection
* Build and compare multiple regression models
* Evaluate model performance before and after data cleaning

---

## 📊 Dataset

The dataset includes:

* Ambient Temperature (AT)
* Ambient Pressure (AP)
* Relative Humidity (RH)
* Vacuum (V)
* Energy Output (PE)

---

## 🔍 Data Preprocessing

* Outlier detection using IQR method
* Data cleaning and visualization
* Correlation analysis

---

## 🤖 Models Used

* Linear Regression
* Decision Tree Regressor
* KNN Regressor
* Support Vector Regression (SVR)
* Random Forest Regressor

---

## 📈 Evaluation Metrics

* R² Score
* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)

---

## 🏆 Results

* Random Forest achieved the best performance
* Data cleaning significantly improved model accuracy

---

## 📌 Key Insight

Outlier removal (IQR method) improved model performance and reduced prediction error.
